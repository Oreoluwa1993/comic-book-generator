# Writing Style Rules

- **No em dashes** ( — ) in any written output. Use a comma, period, colon, or restructure the sentence instead.

# Automation Ideas — Ongoing Rule

After completing any repetitive or manual task, append a short note to
`.claude/automation-ideas.md` using this format:

```
## <date> — <task name>
**What was manual:** <one sentence>
**How to automate/speed up next time:** <one to three sentences>
```

Do this every time without being asked. Never skip it. The file is a permanent
running log — append only, never delete.
