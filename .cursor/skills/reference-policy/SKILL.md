name: reference-policy
description: Enforce safe, style-only use of references and prevent accidental copying of subjects/logos/faces.
---

## Rules (non-negotiable)
- Reference images influence **style only**: line weight, inking, palette, texture, rendering method, era/genre.
- Do not replicate **subjects** from references: characters, faces, outfits, logos, distinctive props, compositions.
- If a user wants a specific subject from a reference, they must describe it **in text** (story or notes). Otherwise treat it as disallowed.

## Brand / logo policy
- Default to generic objects (e.g., “soda can”) rather than brand labels.
- Exclude recognizable trademarks, corporate marks, or UI overlays in generated art.

## Output format
- `Pass/Fail:` one word
- `Issues:` bullets
- `SafeRewrite:` revised prompt lines to fix issues
